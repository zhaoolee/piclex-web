# piclex-web 发版提速实测

2026-11-09。正式发布流程已生效。GitHub Pages 和 Docker 的 Actions 墙钟为 **52 秒**，触发端观察为 **54.412 秒**。双站切换及国内更新服务完成用了 **77.607 秒**，含预检为 **79.235 秒**。初次国内站验收出现 HTTPS 连接超时，后续补验通过。双站 60 秒目标未达到。

- [正式候选](https://github.com/zhaoolee/piclex-web/actions/runs/42553754723) 墙钟 1072 秒，338 项 Node、54 项部署、680 项浏览器通过，4 项既有平台跳过。24 轮性能及原始 trace 汇总、AMD64/ARM64 镜像准备全部成功。候选准备单独计时。
- [正式发布](https://github.com/zhaoolee/piclex-web/actions/runs/42555474856) 复用精确候选。发布作业的 Pages 部署、Docker 晋级与依赖准备并行。Pages 后端从创建到成功耗时 14.766 秒。
- 国内站在第 41.652 秒读到 Pages 候选清单后启动，正式更新与清理在第 77.607 秒结束。首轮浏览器和资源并发核验遇到连接超时。拆分后，浏览器实际导入、触屏切模块、刷新恢复通过。Python HTTP 客户端收到 403，改用标准发布器的 curl 方式复核 14 个资源全部通过。补验加预检共 280.209 秒。保留首轮失败结果。
- 两站实际版本为 `1c4dd3b877ec-a21256792cc7`。两站各 14 个 HTML/JS/CSS 的 SHA-256 一致，国内站验收前后的完整 1207 文件清单摘要一致，仅保留当前静态包。Docker latest 的不可变摘要与两架构均通过核验。
- 对比上一组计时，GitHub 62 秒降到 52 秒。双站历史 122.138 秒含全部线上核验，本次 77.607 秒仅表示切换和服务完成，两者口径不同。最近另一轮 GitHub 460 秒中有 425 秒等待 Pages 服务端。国内站串行依赖 Pages，且外部部署与网络时间存在波动。
