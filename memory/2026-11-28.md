## Web 电影片名、图库入口与自由听写

- 「经典电影台词」在「练听力」的模式与背景声之间以固定 14px 单行显示当前图片的双语电影名。长片名可在该区域横向滑动或用方向键滚动，点按单独模糊或恢复片名，换图时显示新片名。听写草稿、输入焦点及拼单词中文提示的隐藏偏好独立保留。
- 合并候选包含固定在图片区域右上角的三本书图库按钮，图片上下留白时位置保持一致。点图标或照片都可打开同一图库。自由听写显示完整照片、移除彩虹框，拼单词及词块拼句照常显示卡片标注。
- 使用 V29 官方卡组，在隔离 Linux 上通过桌面 Chromium、触屏 Chromium 和 WebKit 共六项定向检查，覆盖影片名点按、320 像素工具栏、图库与分享，以及从《指环王：双塔奇兵》答对后自动切到《蜘蛛侠》时的标题与输入状态。桌面横向滚轮与触屏横滑均可查看长片名，滚动不会模糊标题或切换练习，停稳后仍可轻点模糊。生产构建和 349 项单元测试通过。图库位置已用留白电影剧照在桌面、触屏和深色视口前后对照，核对照片、工具栏、答题区与键盘位置。正式上线结果另记在下方。
